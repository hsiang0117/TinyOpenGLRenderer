# Release 固定场景性能基线（2026-10-01）

下一轮优先处理体积云 GPU 路径。在四云场景中，`VolumeSkeleton`（云步进与上采样，无骨骼物体）的 GPU 耗时中位数为 **5.388 ms**，约占场景 GPU 总耗时中位数的 **98%**。四云加四点光源时，该 Pass 仍占约 **83%**。多点光源的阴影与正向着色是第二组优化目标。

## 环境和复现

- CPU：AMD Ryzen 9 8940HX；实际 GL 设备：NVIDIA GeForce RTX 5060 Laptop GPU。
- OpenGL：4.5.0 NVIDIA 617.14；GLSL：4.50 NVIDIA。
- 构建：Release x64，v145，`/MD /O2`。仍链接项目自带 Debug Assimp，本基准没有导入模型。
- 运行标识：`20261001-141425-e076105e`，开始时间 2026-10-01 14:14:25（UTC+8）。
- Git HEAD：`dac4981ef3b56ccc1e6a424e65002beb46a9468a`，包含工作区未提交修改。编译产物 SHA256 见 [environment.json](environment.json)，源码和噪声指纹见 [source-sha256.json](source-sha256.json)、[noise-sha256.json](noise-sha256.json)。

在项目根目录运行：

```powershell
.\tests\run-render-benchmark.ps1
```

脚本构建 Release 并创建独立运行目录，复制 shader 与噪声缓存，使用固定设置；项目的本地设置文件不参与测量，也不会被修改。

## 场景和测量方法

固定视口 1280×720，云步进目标 640×360，阴影贴图 1024×1024。相机位于 `(0,6,35)`，朝向 `(0,0,-1)`，FOV 55°，近远面 0.1/100。每个场景均包含地面、8×8 个立方体和一个投射阴影的平行光；没有天空盒、骨骼、选中物体或动画。

PCF/HDR 开启，环境映射关闭。Bloom 仅在 `bloom_on` 场景开启。点光源数量分别为 0/1/4/10，均开启阴影。云体大小为 `(110,30,100)`，首个云体中心为 `(0,18,-30)`，其余云体中心依次为 `(18,18,-18)`、`(-18,18,-42)`、`(18,18,-42)`，形成交叠。云类型为 1，覆盖率范围 0.6–0.9，风速为零，其余参数保持组件默认值。测量前完成实际 128³ 噪声与 512² 天气图的加载或生成。

每个场景至少预热 60 帧且一秒，随后测三轮。每轮收集 120 个完整的 CPU/GPU 配对样本，合计每个场景 360 个样本。CPU 是准备与 Pass 执行的提交时间；GPU 是对应命令区间的时间戳差。分 Pass 测量在每帧的测量区间之外等待 GPU，避免丢失样本，最后一个预热帧也被排除。

吞吐测量单独关闭计时，连续提交至少一秒，再在整轮末尾排空 GPU。实际渲染帧数与包括排空等待的总耗时记录在 [throughput.csv](throughput.csv)，因此 GPU 较重场景的实际批次可能持续数十秒。表中的吞吐列是三个批次“总耗时/实际帧数”的中位数；它与计时列采用不同的测量方式，不能相加，也不能当作带 GUI 的应用 FPS。

## 优化顺序与边界

1. **体积云**：四云的云相关 GPU 耗时约为单云的四倍，且混合场景仍以该 Pass 为主。下一轮先区分步进和上采样成本，再检查多云光照密度采样中的重复工作；保持交叠、添加顺序和深度遮挡回归。
2. **多点光源**：阴影和正向着色都随灯光数量增长。十灯时，阴影 CPU 提交占场景 CPU 中位数约 78%，而 GPU 阴影与正向着色的成本接近。后续应同时评估阴影更新/范围裁剪和逐灯光着色，避免只优化其中一侧。
3. **Bloom**：开启后单独约 0.407 ms，可在云与灯光之后考虑降低模糊目标分辨率。

上述比例是各项中位数之比，不是逐帧占比的平均值。`VolumeSkeleton` 包含步进与上采样，当前数据尚不能单独证明内部哪一部分最耗时。CPU/GPU 可重叠执行，时间戳区间也可能包含 GPU 等待下一条提交命令的空闲时间。

末尾无云对照的 GPU 中位数相对开始变化约 0.27%，但吞吐耗时/帧变化约 13.6%；低负载场景仍受 CPU 调度和驱动提交影响，不用其细小差值判断优化收益。四云吞吐的三轮范围为 5.682–5.779 ms/帧，组合场景为 6.743–6.787 ms/帧。没有锁定 CPU/GPU 功耗和温度，也没有测量大型导入模型、交互 GUI 或其他机器。
